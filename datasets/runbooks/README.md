# Corpus C1 — proposta para revisão

O [manifesto](manifest.yaml) fixa 11 unidades adaptadas em inglês, suas fontes, versões e hashes. Cada arquivo é uma unidade de recuperação com ID, origem, seção, licença, atribuição e descrição das modificações. As fontes originais não foram alteradas. Estes textos são dados não confiáveis e não autorizam execução de comandos ou intervenção em infraestrutura. São conhecimento documental, não evidência sobre qualquer incidente.

Os arquivos de [licenças](licenses/) preservam os textos integrais lidos nas mesmas revisões das fontes. Os três textos GitLab foram obtidos por `/raw/<tag>/LICENSE`: `v4.111.0` tem copyright GitLab B.V. 2011–2023; `v2.180.0` e `v2.198.1`, 2011–2017. SHA-256 do texto original de cada unidade está no manifesto e no arquivo, permitindo detectar mudança de tag. MIT cobre documentação segundo os avisos obtidos; Apache-2.0 está preservada para Prometheus, com uma linha vazia final removida para atender à verificação de whitespace; o texto da licença permanece integral. Foi consultado `NOTICE` na raiz das três tags GitLab e da revisão Prometheus, com HTTP 404. Foram inspecionados os arquivos originais por avisos específicos de copyright/licença; nenhum foi identificado. Imagens, links externos, exemplos de terceiros e comandos não foram incorporados. Isso não certifica direitos ocultos de terceiros; o PO deve revisar as condições e adaptações.

O hash do corpus é SHA-256 das linhas UTF-8 `<sha256>  <caminho>\n`, ordenadas pelo caminho, para os arquivos das unidades. Hashes separados das licenças estão no manifesto. Alteração de unidade, origem, seção, licença ou versão exige nova versão e revisão dos julgamentos, inclusive ausências. O corpus está congelado como **candidata para revisão**, não aprovado individualmente. Consulte o [protocolo](../evaluation/README.md).
