# Revisão dos 22 casos — proposta ao PO

Versão `HYP-2026-11-06.3-descritiva-proposta`. **Todos os casos e rótulos aguardam revisão do PO**, inclusive os marcados como “manter”. Esta tabela é análise do executor, não aprovação humana nem resultado de experimento. “Simulada” é uma resposta preparada para verificar a rubrica; “geração” é uma solicitação para uso em futuro teste autorizado; “falha simulada” é um evento de teste, não falha observada da aplicação. As evidências são somente as disponibilizadas ao caso; caminhos, hashes, períodos, estímulos integrais e versões estão no [dataset](cases.yaml). IDs de runbook identificam orientação documental, não sinal observado.
